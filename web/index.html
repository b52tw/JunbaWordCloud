掃碼打不開？

確認手機與筆電在同一個網路。上方若有多個網址，請選擇實際使用的 Wi-Fi 網址，避免 VPN 或虛擬網卡。

學校網路無法使用時，可由一支手機開啟熱點，讓筆電與其他手機一起連入，再按上方重新偵測。熱點可連線人數及裝置互通能力依手機而定。

Windows 詢問防火牆時，允許此程式在您信任的「私人網路」通訊。學校訪客 Wi-Fi 可能有裝置隔離，建議自備分享器。手機若提示此 Wi-Fi 沒有網際網路，請選擇繼續連線。
